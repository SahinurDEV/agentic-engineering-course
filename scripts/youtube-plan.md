## Daily workflow for each episode
1. Review the lesson material for that day.
2. Script: intro hook (30 s), the concept, a live demo, a recap, and a call to action. Keep the spoken lines clean for text-to-speech.
3. Slides: one short deck per episode.
4. Demo code: a public GitHub repo, one folder or branch per episode.
5. Generate the AI voiceover from the script's spoken lines.
6. Record the screen demos.
7. Assemble slides + screen recordings + voiceover into the video, edit, and add a thumbnail and chapters.
8. Upload to YouTube as Unlisted and put it in the course playlist, with a Week playlist per section.

## Resources per week
- Week 1 (Days 1-7): setup guide, Claude Code cheat sheet, prompt checklist.
- Week 2 (Days 8-14): plan template, CLAUDE.md template, subagent examples.
- Week 3 (Days 15-23): skill templates, hooks config, MCP setup guide.
- Week 4 (Days 24-28): OpenSpec example spec, GitHub workflow file, Conductor notes.
- Week 5 (Days 29-36): capstone repo with a branch per episode.
