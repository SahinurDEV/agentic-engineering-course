### 0:55–1:25 · What you'll be able to do by the end
**Marker:** [VOICEOVER + SLIDE]

**Say:**

> extend it with subagents, skills, hooks, and MCP servers;
> drive features from written specs with OpenSpec;
> hook it into GitHub and run several sessions in parallel with Conductor;

### 1:25–2:05 · The 5-week structure
**Marker:** [VOICEOVER + SLIDE]

> Week three: extending the agent with skills, hooks, and MCP.
