## What this episode covers

We set up the capstone Support Desk: Laravel 13, React starter kit, PostgreSQL, R1 checked, CLAUDE.md, skills, hooks, reviewer, Playwright MCP, OpenSpec, CI and the first commit. Screens are drawn illustrations; no output is shown. Files are written for the course; docs/requirements.md is in the Episode 28 description.
