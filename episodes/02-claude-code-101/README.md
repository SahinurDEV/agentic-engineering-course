## What this episode covers

Claude Code is Anthropic's agentic coding tool. It runs in your terminal, works across your whole project, and can read files, search, edit code, and run commands. In this episode I explain what Claude Code is and how to install and start it, how it works (the agent loop of gathering context, taking action, and verifying, plus the tools behind it), how permission prompts keep you in control, and the anatomy of a session, walked through step by step: from typing claude in a project folder to reviewing the diff. I also cover what fills the context window and the first commands to know: /help, /context, /clear, Esc, /exit, and claude --continue.

"You don't paste context in. It goes and gets it. You decide what it's allowed to do."
