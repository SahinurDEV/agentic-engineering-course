## What this episode covers

AI coding has moved from autocomplete (you drive, it suggests) to agents (it drives, you steer). In this episode I explain what agentic engineering actually means, walk through the autocomplete loop vs the agent loop (Read → Act → Verify), compare the same small task done two ways (chat-style copy-paste vs Claude Code working in the repo), and explain why your engineering fundamentals matter more than ever.

"The bottleneck is no longer typing. It's specifying, reviewing, verifying."
