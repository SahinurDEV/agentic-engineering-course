## What this episode covers

We define the project we build for the rest of the course: a Support Desk where customers open tickets and agents reply, assign and resolve them. Then we write its requirements, line by line, and map every tool from the course onto the build: CLAUDE.md, planning, skills, hooks, MCP, specs, GitHub and worktrees. Stack: Laravel 13 with the React starter kit, and PostgreSQL. No code in this episode, on purpose. Screens are drawn illustrations; no Claude output is shown. The file and prompt below are written for the course.
