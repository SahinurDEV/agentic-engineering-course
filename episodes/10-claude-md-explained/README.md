## What this episode covers

In this episode: what CLAUDE.md is (persistent instructions loaded at the start of every session, as context, not enforced config); how it differs from auto memory; where the files live (user, project, local, managed policy, subfolders) and how they load; what belongs in it (commands, style rules that differ from defaults, architecture decisions, gotchas, workflow rules) and what stays out (long docs, what the code already shows, secrets); keeping it concise; @imports; then a line-by-line review of a sample CLAUDE.md for a small cart project.

Note: screens are drawn illustrations, and the sample CLAUDE.md is an example written for the course, not from a real repository.
